# secure-egress-gateway
Учебный проект по системному анализу: корпоративный шлюз контролируемого доступа сотрудников к внешним сервисам. AS-IS/TO-BE, требования, модель угроз, процессы, API.

**Мотивация**
Многие IT-компании сталкиваются с тем, что часть нужных внешних сервисов недоступна напрямую. На практике это решают подручными средствами: прокси на арендованном сервере, коммерческие VPN, индивидуальные туннели. Такие решения обычно возникают стихийно, без единой политики, аудита и понимания, какие данные через них проходят.

Этот проект — попытка посмотреть на проблему из опыта в реальной IT компании, как системный аналитик: описать текущую ситуацию, выявить риски (перехват трафика, недоверенные посредники, отсутствие аудита, юридические ограничения) и спроектировать контролируемую замену. Проект учебный, основан на обобщённых сценариях и не отражает практику конкретной организации.
